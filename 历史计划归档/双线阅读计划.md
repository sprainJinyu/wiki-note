# 双线阅读计划

每次阅读前，选一条线，顺着顺序往下读下一章。

| 线 | 书籍 | 方向 |
|----|------|------|
| 📚 **正面管教线** | 《正面管教》（玉冰译，12章） | 教育/理解人/团队协作 |
| 🖥️ **技术线** | 4 本书混读：「理论地基+实践应用」 | 架构能力 + 全局思维 |

技术线阅读原则：**先理论后实践**。每次技术阅读，先读一段 DSI 理论，再读对应章节的实践内容。互相映照。

## 🖥️ 技术线（4 本书混读）

### 混排逻辑

| 书籍 | 角色 | 覆盖层面 |
|------|------|----------|
| 🟡 **《Distributed System Illustrated》**（DSI） | 理论地基 | 复制/共识/分区/事务/时间 — 分布式底层原理 |
| 🔵 **《系统设计面试》** | 系统全貌怎么画 | 架构实践 |
| 🟢 **《领域驱动设计》** | 业务边界怎么划 | 为什么这么做 |
| 🔴 **《重构》** | 代码层面怎么判断好坏 | 该怎么改 |

DSI 是新增的 **理论地基层**，为其他三本书的实践内容提供底层支撑。

### 混读节奏

每次技术阅读，先读一段 DSI（理论），再读对应的实践章节。DSI 离线缓存于 `notes/阅读/distributed-system-illustrated/`，含 184 张插图。

## 每次阅读的常规步骤

不管选哪条线，都按这个节奏：

```
选线 → 翻目录（只看选中那章） → 扫读核心内容 → 问自己两个问题：
  1. 这一章的核心概念/方法是什么？
  2. 对我现在有什么启发？
→ 写 1-3 句摘抄（存到对应的笔记文件）
→ 下一次阅读时选另一条线或者继续同一条线
```

> **原则**：不贪多、不强记。工具书是用来查的，不是用来背的。
