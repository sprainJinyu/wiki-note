# 主题：从业务代码到分布式系统

**编排逻辑：从你日常写的业务代码出发，逐层向上/向下抽象，最终建立从代码到分布式系统的完整知识链条。**

```
业务代码写不好 → 先学怎么识别坏味道 + 重构 → 再学怎么划业务边界 → 然后看系统从小规模到大规模的演进 → 最后学分布式系统底层原理
```

## 📌 核心目的呼应

正好对应你说的问题：
- 问题："工作仅聚焦业务层，没有从整体考虑"
- 解决：从业务代码出发，每一步都往上抽象一层，直到分布式系统底层，最终你就能：
  1. 写业务代码时，知道怎么写才好
  2. 设计系统时，知道为什么这么设计
  3. 出问题时，能往下挖到分布式底层原理找根因
