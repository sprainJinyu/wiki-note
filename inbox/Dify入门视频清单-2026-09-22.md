## 给技术人的概念速记

- Dify = 拖拽式 LLM 应用编排平台（LangChain/LangGraph 的可视化低代码版 + RAG + Agent），开源（社区版 GitHub docker 自托管；云版有沙盒）
- 五类应用形态：Chatflow / Workflow / Agent / 文本生成 / 应用模板
- 核心概念：节点（LLM/知识检索/代码/HTTP/工具）、变量、知识库（Chunk+Embedding+向量检索）、插件生态（模型供应商走 plugin）
- 与你的「Harness Engineering」兴趣直接相关——Dify 就是一门「LLM harness 的可视化实现」
