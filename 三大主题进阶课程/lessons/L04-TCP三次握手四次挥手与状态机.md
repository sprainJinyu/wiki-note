# L04 · 三次握手排除旧 SYN；四次挥手因为可以半关

> **今天只带走这一条**：三次握手是为了确认双方都能收发，并丢掉过期的 SYN；四次挥手是因为 TCP 允许一边先关、另一边继续发。`TIME_WAIT` 在主动关闭方，`CLOSE_WAIT` 在已经收到 FIN、应用还没 close 的那一端。
> **用时**：15–20 分钟。

---

## 1. 原理

```
客户端                                          服务端
  │  1. SYN, seq=x                                │  LISTEN → SYN_RCVD
  ├──────────────────────────────────────────────>│
  │  2. SYN+ACK, seq=y, ack=x+1                   │
  │<──────────────────────────────────────────────┤
  │     （此时客户端 → ESTABLISHED）                │
  │  3. ACK, ack=y+1                              │  → ESTABLISHED
  ├──────────────────────────────────────────────>│
```

三次不是仪式。两次只能证明「我能发、你能回」，不能证明「你也能收到我后续的确认」；另外，网络里可能还飘着很久以前的 SYN，三次可以把它和新连接区分开。

```
主动关闭                                          被动关闭
  │  1. FIN                                       │  ESTABLISHED → CLOSE_WAIT
  ├──────────────────────────────────────────────>│
  │  2. ACK                                       │  （内核先回 ACK，应用稍后 close）
  │<──────────────────────────────────────────────┤
  │     FIN_WAIT_2                                │
  │  3. FIN                                       │  CLOSE_WAIT → LAST_ACK
  │<──────────────────────────────────────────────┤
  │  4. ACK                                       │  → CLOSED
  ├──────────────────────────────────────────────>│
  │  TIME_WAIT（等 2MSL）再 CLOSED                 │
```

连接是双向的，一边说「我不再发了」不等于另一边也说完。所以是四次，不是三次。若被动方在回 ACK 的同时刚好也 FIN，可以叠成三次报文，那是合并，不是另一套协议。

两个线上常见状态：

* **TIME_WAIT**（主动关闭方）：最后那个 ACK 可能丢，对端会重发 FIN；还要让旧连接的报文在网上死掉。等 2MSL 是正常的。短连接太多会占端口，方向是复用连接，不是「消掉 TIME_WAIT 就好」。
* **CLOSE_WAIT**（被动关闭方）：已经收到 FIN，内核回了 ACK，**本进程还没 `close()`**。常见于连接没还回池、流没关、线程卡住。先当本进程的问题查，不先当「网络抖动」。

---

## 2. 误区

**「CLOSE_WAIT 很多 = 一定是 Java 写错，和网络无关。」**  
主因确实在本端没 close，但「没 close」包括泄漏、线程卡死、池耗尽，不是只有漏写 `finally`。先查本进程，不要说成「100% 某一行代码」。

**「TIME_WAIT 是故障，应该调内核立刻清掉。」**  
它是主动关闭方的正常保护。优先长连接 / 连接池。

---

## 3. 自检

1. **主动关闭方为什么要进 TIME_WAIT，而不是发完最后一个 ACK 就消失？**
   *提示：ACK 丢了对方会重发 FIN；还要隔离旧连接的迟到报文。*
2. **机器上某端口堆了几千 CLOSE_WAIT，先查网线还是先查本进程？**
   *提示：先查本进程有没有把 socket close 掉。*
