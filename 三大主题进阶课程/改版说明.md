# 三大主题课程改版说明

本文只记录这一版**为什么改、改成什么、刻意没做什么**。课程怎么用，看 [[00-课程总览与大纲]]。

---

## 1. 原因

原方案（2026-08-17）把三件事绑在一起：

1. 通勤 20 分钟读原理；
2. 用虚构的 `retrytask` 示例当「工程映射」；
3. 周末在 `member-user-center` 上重构、压测、做 DDD 落地。

实际约束只有第一条成立：碎片时间适合学原理，不适合做重活。后两条会抢通勤分钟，还把「看过一个叫 RetryTask 的例子」误当成「懂了这条原理」。

对照磁盘和代码之后，还有三个硬事实：

- 总览写「一次性交付 20 课 + 4 专项」，实际只写了 L01–L08 和 W01。
- 映射里的类（`RetryTaskRunner`、`RetryableExceptionClassifier`、退避调度器）大多不是 `retrytask` 里的代码。
- `RetryTaskServiceImpl` 注入了 `RedisLockRegistry` 却从未加锁；消费端异常后仍 `ack`。这些真问题不该用通勤卡去「改生产」解决。

所以这一版按使用方式改结构，而不是把没写完的课表补齐。

---

## 2. 目的

1. **一张卡只带走一条原理**，15–20 分钟能读完，读完能用自己的话复述。
2. **去掉重活**：不改生产、不写周末专项欠债、不把 Wiki 张数当完成标准。
3. **修会在碎片学习里固化的错句**（例如「volatile = 每次从主内存读」、AQS Dummy Head「等于持锁线程」）。
4. **三套卡可抽读**，不必四周齐头并进，也不必绑在同一个 MVP 上。

---

## 3. 思路

### 3.1 产品是原理卡，不是课程班

并发、网络、DDD 做成三套互相独立的卡组。每天抽一张，顺序建议按卡组内箭头走，跨组不必同一周读完。

### 3.2 统一卡片模板

每张卡只保留四块：

1. **原理**：一条判断 + 一张图或表
2. **误区**：一句容易记住的错话，以及为什么错
3. **自检**：两题，先想再看提示
4. **资料**：指向本目录 `materials/` 里真实存在的文件

原「源码与工程映射」整节删除。和业务的关系最多留在误区里一句，不再虚构 `retrytask` 类。

AQS 这种 20 分钟装不下的主题：**正文只记三要素，流程放附录，附录标明通勤不必读。**

### 3.3 砍什么、留什么

| 处理 | 对象 | 理由 |
| :--- | :--- | :--- |
| 已写，按模板收材 | L01–L08 | 本来就是原理卡，去掉映射、修口径 |
| 降为可选轻验证 | W01 | 只验证「无同步可能看不见」；抓包可选；不进生产仓库 |
| 从必读拿掉 | L09、L10、L20、W02–W04 | 读仓库 / 改生产，不是碎片原理 |
| 待写，仍算原理卡 | L11–L12 线程池收尾；L13–L14 RTO/零窗口；D01–D04 DDD | 值得写，但本版不假装已经交付。编号见总览 |
| 不写 | 「RetryTask 充血重构」 | 对象选错（支撑域），且是重活 |

### 3.4 本版故意不做

- 不补全 20 课装完整感。
- 不把 `retrytask` 源码对照写进通勤卡。真要读代码，单独立阅读清单，不和原理卡混。
- 不改 `member-user-center`。
- 不重建 Obsidian 产出路径。读完能复述即完成。

## 4. 分课改了什么

| 课 | 改动要点 |
| :--- | :--- |
| L01 | 一条原理改成「无同步不保证可见」。工作内存标明是抽象。删掉 `RetryTaskRunner`。不再把 volatile 说成「每次从主内存读」。 |
| L02 | 保证写成：可见 + 有序，复合操作无原子性。屏障留程序员该记的部分；`lock addl` 降为 x86 实现细节，不背汇编。DCL 改放到误区。 |
| L03 | 保留八条 HB 表。安全发布例子去掉 Retry 包装。 |
| L04 | 保留握手/挥手。CLOSE_WAIT 不再写成「100% Java Bug」。删 RestTemplate/TIME_WAIT 恐吓故事。 |
| L05 | 保留 RST vs Timeout。删虚构异常分类器。非幂等接口超时重试放到误区。 |
| L06 | 保留对比表。`tryLock` 只说明超时获取，不编重试调度器。锁升级放入附录。 |
| L07 | 正文只留 `state` / 持锁线程 / 队列三要素。Dummy Head 纠正为哨兵。acquire 流程改附录。 |
| L08 | 保留 CAS 三要素与 ABA。改正「先取 stamp 再 CAS」的 TOCTOU 示例。乐观锁对照改为一句 SQL。 |
| W01 | 可选。Demo 不放生产测试目录。写明：不复现 ≠ 没有可见性问题；`interrupt()` 打不断空转。Wireshark 改为有余力再做。 |

## 5. 和旧计划的关系

2026-08-07 的切片计划（已归档）只排两周、周末再评估，时间模型是对的，但仍然以 `retrytask` 改造为锚。

2026-08-17 的「4 周 24 课一次性交付」把完整课表模板套了进来，完整感上升，可完成性下降。

**2026-08-21 这一版**：保留 08-17 的独立课卡形态，退回「碎片只学原理」，不再用完整课表和生产锚点驱动。

## 6. 旁听与答疑

Antigravity / Gemini 的问题和 Grok 的答复记在 [[agent-discussion]]，不写进本说明。好建议落地后再回写本节或分课表。连续 6 轮无新的 `待答` 即停扫；有新问题再开。

Round 2 采纳：待写卡按卡组编号（L11/L12、L13/L14、D01–D04）；队列不拆三张；DDD 第一批不含领域事件。正文仍未写。

Round 3 采纳：`progress.md` 收成 16 张 + W01，已写可勾、待写只列题。拒绝一次性写完 L11–L14、D01–D04。

Round 4 采纳：原理/误区可有 3～5 行代码嗅觉（不是新板块）；默认推荐单通并发→网络→DDD；TLS 与 DDD 草稿纸列入暂缓/可选，不进 16 张。L06 补了 `tryLock` 五段。拒绝把 TLS 塞进当前 4 张 TCP 收尾。
