# 三大主题原理卡总览

> 碎片时间只读原理。三套卡互相独立，每天抽一张，读完能复述即完成。
> 改了什么、为什么改：[[改版说明]]。

---

## 怎么用

* **一次一张，15–20 分钟。** 不要在通勤里写代码、读生产仓库、改 Wiki。
* **推荐主线**：先单通并发已写 6 张（L01→L02→L03→L06→L07→L08），再网络 L04→L05，DDD 等有正文后再走 D01→D04。待写卡接在各卡组末尾。这样 HB、AQS 这种链式原理不会读到一半被掐断。
* **允许抽读**，但换组会断上下文。不要为了换口味把 L03 读到一半去读握手。
* **附录通勤不必读。** 正文只留一条原理。
* **完成标准**：用自己的话讲出那一条判断。勾选 [[progress]]，不要勾代码或 Wiki。

每张卡四块：原理（一条 + 一图表）→ 误区 → 两道自检 → 资料。

原理或误区里**可以**有 3～5 行代码或一条过滤表达式，这不是第五块。没有 Java 的卡（握手、RST）用报文图即可。禁止为了「像课」贴虚构业务类。
