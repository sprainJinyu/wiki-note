# 三大主题原理卡总览

> 碎片时间只读原理。三套卡按主题彻底独立，每天抽一张，读完能复述即完成。

---

## 怎么用

* **一次一张，15–20 分钟。** 不要在通勤里写代码、读生产仓库、改 Wiki。
* **推荐主线**：**先单通并发卡组（C01 ➔ C06），再通网络卡组（N01 ➔ N02），最后进 DDD 卡组（D01 ➔ D04）。** 待写卡接在各卡组末尾。这样 HB、AQS 这种链式原理不会读到一半被掐断。
* **附录通勤不必读。** 正文只留一条原理。
* **完成标准**：用自己的话讲出那一条判断。勾选 [[progress]]，不要勾代码或 Wiki。

每张卡固定四块：**原理（一条 + 一图表） ➔ 误区辨析 ➔ 两道自检题 ➔ 资料索引**。
原理或误区里保留 3～5 行代码嗅觉或抓包过滤表达式，贴合实战直觉，拒绝冗长假类。
