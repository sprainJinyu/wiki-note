# 主题原理卡总览

> 碎片时间只读原理。各套卡按主题彻底独立，每天抽一张，读完能复述即完成。

---

## 怎么用

* **一次一张，15–20 分钟。** 不要在通勤里写代码、读生产仓库、改 Wiki。
* **推荐主线**：
  * **主线 A（Java 并发内功与实战）**：单通并发卡组（`C01 ➔ C15`，阶段1底层 ➔ 阶段2核心工具 ➔ 阶段3现代实战与排查）；
  * **主线 B（分布式通信与消息）**：网络卡组（`N01 ➔ N02`） ➔ Kafka 卡组（`K01 ➔ K05` ➔ `K06 ➔ K10`）；
  * **主线 C（业务架构）**：DDD 卡组（`D01 ➔ D04`）。
* **附录通勤不必读。** 正文只留一条原理。
* **完成标准**：用自己的话讲出那一条判断。勾选 [[study-progress]]，不要勾代码或 Wiki。

每张卡固定四块：**原理（一条 + 一图表） ➔ 误区辨析 ➔ 两道自检题 ➔ 资料索引**。
原理或误区里保留 3～5 行代码嗅觉或抓包过滤表达式，贴合实战直觉，拒绝冗长假类。
