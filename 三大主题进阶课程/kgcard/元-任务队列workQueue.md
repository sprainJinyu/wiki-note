# 元-任务队列workQueue

任务队列是线程池里存放待执行任务的容器。  
货在队列里，人是 [[元-工作线程Worker]]，由 Worker 去跑任务。

它不是 AQS 的同步队列，也不是条件队列。后两者是柜门锁的内部结构。

## 巧思 / 细则

队列有不有界、长不长，决定 `offer` 会不会失败，从而决定进池第 3、4 段出不出得来。  
容量为 0 时没有冗余存放缓冲，新任务只能靠新造 Worker 消化。  
默认长度为 `Integer.MAX_VALUE`（约 2^31-1）时，可以理解成很大很长，实际上很难放满。
