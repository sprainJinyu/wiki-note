# 元-任务队列workQueue

`workQueue` 是线程池里存放待执行任务的阻塞队列。  
任务放在这条队列里，由 [[元-工作线程Worker]] 取出后执行。

它不是 AQS 的同步队列，也不是 Condition 的条件队列。后两者属于阻塞队列内部锁的实现结构。

## 巧思 / 细则

队列是否有界、容量多大，决定 `offer` 会不会失败，从而决定进池第 3、4 段出不出得来。  
容量为 0 时队列不存放任务，新任务只能靠新建 Worker 消化。  
默认容量为 `Integer.MAX_VALUE`（约 2^31-1）时，实际上很难 `offer` 失败。

口述用名（用户）：容量为 0 的那种阻塞队列，对应类名 `SynchronousQueue`。不称「同步队列」，避免和 AQS 同步队列重名。
