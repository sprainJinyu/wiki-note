# 元-等待队列哨兵

`head`、`tail` 是 AQS 对象自己的两个指针，不长在哨兵 Node 里面。  
`head` 常常指向一个不代表等待线程的空 Node，这就是哨兵。

哨兵与后面那些等待节点不是一类。它要解决的是「队列还在不在」：第一次有人失败要排队时先放一个空 Node，之后入队都接在当前 tail 后面。  
它不省「一个还是多个等待者」的判断，也不让 `head.next` 永远非空。

## 巧思 / 细则

被唤醒的线程重新抢到锁之后，自己变成新的队头，也就是新哨兵，从等待队列里被分割出去，不再是等待者。  
最后一个等待者拿到锁后，不必把整条队列拆掉；`head` 和 `tail` 可以都指向这个空哨兵，等下一次有人入队再改 `tail`。
