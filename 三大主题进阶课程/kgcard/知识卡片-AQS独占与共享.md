# 知识卡片-AQS独占与共享

**组成元知识点**：  
[[元-AQS不是锁]] · [[元-AQS三要素]] · [[元-state在可重入锁中的双重含义]]

**核心表述**（基于用户口述润色）：  

AQS 定的是一套同步规则，不等于锁。独占和共享都是这套规则上的应用。

独占：初始 `state` 为 0。有人占领后大于 0，并可按重入往上自增；别人进入排队。

共享有两种常用场景：

- 信号量：`state` 是还能发出去的数量。变成 0 表示发完了，后来的人排队；有人释放才能把数量返还回来，数量可以反复用。
- 计数门闩：单向一直减到清零。清零之后大家达到一个统一状态，再进行下一步；许可不需要还回来。
