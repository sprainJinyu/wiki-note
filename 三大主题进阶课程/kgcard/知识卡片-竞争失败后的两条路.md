# 知识卡片-竞争失败后的两条路

**组成元知识点**：  
[[元-CAS]] · [[元-等待队列哨兵]] · [[元-公平锁与非公平锁]]

**核心表述**（基于用户口述润色）：  

抢资源先 CAS 改 `state`。不成功就入队；前驱还不是哨兵则 `park` 休眠，前驱已是哨兵会再试一次，再失败才睡。  
唤醒的人不是哨兵自己，是释放锁的人唤醒 `head` 的后继。被唤醒后再 CAS，成功则自己成为新哨兵。  

自旋占着 CPU 反复试；入队睡觉把 CPU 让出，醒来付切换成本。两者互斥，入队并 park 之后不再空转。  
非公平时活跃线程可能插队，排队者可能饥饿——饥饿来自插队，不是来自自旋本身。
